# 7. 命名规范

## 7.1 严禁

- 严禁使用字母、语义不明确的字符进行命名
- 必须使用语义化的英文单词命名

## 7.2 Rust 命名法速查

| 类别 | 命名法 | 例子 |
|------|--------|------|
| 函数名 | `snake_case` | `calculate_total_price` |
| 变量名 | `snake_case` | `user_age` |
| 类型名(struct/enum/trait) | `CamelCase` | `UserProfile`, `OrderStatus` |
| 常量 | `UPPER_SNAKE_CASE` | `MAX_RETRY_COUNT` |

> **详细命名规则和 5.2 节重复**,完整对照表见 `references/05-type-annotation.md` 的 5.2。
